### Summary of Changes (Wave 8: AST Duplication & DRY Remediation)

This PR executes **Wave 8** of the continuous autonomous kernel DRY remediation campaign, targeting statement-level AST duplications detected by `zqk-vet --suite hygiene` across `cmd/zqk/object`, `cmd/zqk/docman`, `cmd/zqk/app`, `cmd/zqk/automation`, and `pkg/cliapp`.

#### Key Refactorings & Abstractions:
1. **`cmd/zqk/object` Creation Pipeline**:
   - Extracted `finalizeObjectCreation` and `executeObjectStorageCreate` in `create_helpers.go`.
   - Unified object normalization, prepare/dry-run checks, flag parsing, and storage creation between `RunCreateWithData` and `runCreate`.
2. **`cmd/zqk/object` Inspect & TUI Panel Rendering**:
   - Extracted `initTerminalLines` and `renderPanelOutput` in `inspect.go`.
   - Refactored `inspectSingleObject` and `runPolicyStudio` to share panel setup and terminal formatting.
3. **`cmd/zqk/object` Lifecycle Transition Batch & Probe State**:
   - Extracted `executeLifecycleTransitions` in `transition_helpers.go` to unify batch transition context setup, object resolution, mutation visibility flushing, and error reporting.
   - Introduced `candidateProbeState` in `transition_helpers.go` to eliminate duplicative candidate probe status and rejection mapping.
   - Refactored `promote.go` (`promoteObjectIDs` / `promoteTarget`) and `demote.go` (`runDemote` / `demoteTarget`) to use this shared architecture.
4. **`cmd/zqk/object` Test Helpers**:
   - Extracted `copyFileToTarget` in `test_helpers.go` to deduplicate recursive directory walking and file copying across `copySpecFiles` and `copyCliSpecsTree`.
5. **`cmd/zqk/docman` Environment & Command Runners**:
   - Extended `docmanEnv` to hold flag-derived configuration (`subtrees`, `shippedOnly`, `logger`).
   - Added `withDocmanEnv` command runner wrapper in `docman.go` and refactored `runVerify` and `runRegister` to eliminate boilerplate environment resolution.
6. **`pkg/cliapp` Audit Coordination**:
   - Introduced `cli.InitAuditCoordination` in `pkg/cliapp/audit_coordination.go` to wrap logging profile contexts, instantiate storage coordinators, and initialize audit metadata.
   - Refactored `cmd/zqk/automation/lint_bypass_coordination.go` and `cmd/zqk/app/create_command_audit_coordination.go` to use this shared helper, eliminating duplicate `createContextWithLoggingProfile` implementations and unused profile constants.
