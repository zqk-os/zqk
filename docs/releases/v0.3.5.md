# Release Notes: ZQK Knowledge Kernel v0.3.5

**Release Version**: `v0.3.5` (Release Candidate `v0.3.5-rc1`)  
**Target Date**: November 2026  
**Commit Range**: `v0.3.4..HEAD`

## Highlights & Strategic Capabilities

The `v0.3.5` release delivers major advancements in vendor isolation adapter architecture, automated CI coverage aggregation, multi-scenario evaluation streaming, distributed consensus, and autonomous daemon overseer supervision:

### 1. Vendor Isolation Adapter Architecture & Third-Party Decoupling (`pkg/adapters/ide/`)
- **Pluggable Adapter Drivers**: Encapsulated Cursor, Claude Code, Cline, Windsurf, Antigravity, and generic IDE host integrations into decoupled drivers implementing standard adapter interfaces.
- **Zero Core Vendor Strings**: Completely refactored `pkg/mcp/install.go` to eliminate third-party product names, paths, and platform heuristics from core packages.
- **Fail-Closed Sovereignty**: Strict node sovereignty protection preventing unintended host-global MCP configuration overrides.

### 2. Automated CI Coverage Aggregation & Duplication Elimination Gate (`pkg/coverage/`)
- **Zero-Duplication Execution**: Eliminated redundant monolithic extended test runs in GitHub Actions CI, reducing PR feedback cycles by over 13 minutes per run.
- **100% Package Matrix Partitioning**: All 200+ packages in `pkg/` and `cmd/` are partitioned across 7 parallel matrix shards.
- **Consolidated Shard Rollup**: Deterministic coverage aggregation tool (`scripts/open-core/coverage-rollup`) merges parallel shard profiles and verifies cryptographic `.sha256` integrity.

### 3. Multi-Scenario Batch Evaluation Runner & Real-Time Telemetry Streaming (`pkg/eval/`)
- **High-Throughput Evaluation**: Parallel evaluation harness executing complex multi-step scenario matrices with sub-millisecond dispatch.
- **Live Telemetry Streaming**: Event-driven progress and scorecard emission for evaluating agent accuracy, cost, and latency budgets.

### 4. Multi-Agent Consensus Ledger & Epistemic Shockwave Settlement Invariants (`pkg/consensus/`)
- **Distributed Consensus**: Provable multi-seat consensus protocol managing concurrent agent updates to kernel state.
- **Epistemic Shockwave Settlement**: Idempotent lease transitions that propagate validated changes across the ontological DAG without race conditions.

### 5. Autonomous Daemon Overseer Supervision & Callback-Driven Wake Invariants (`pkg/daemon/`)
- **Watchdog Overseer**: Native host supervisor managing long-running kernel services with automatic crash recovery.
- **Reactive Wake Semantics**: Eliminated busy-waiting loops in favor of OS-level callback notifications and event-driven timers.

### 6. Automated Documentation Portal CI Invariant & Link Rot Sentinel
- **Continuous Doc Validation**: Every PR strictly verifies link integrity and markdown hygiene across all published documentation.
- **Automated Deployment**: One-command portal builds and zero-downtime deployment to `docs.zqk.dev`.

## Upgrade Guide

- **Zero Breaking Changes**: Fully backwards compatible with existing `.zqk/process` repositories and schemas.

  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **Post-Upgrade Verification**:
  ```bash
  zqk system check --refresh-cache
  zqk workflow whats-next
  ```
