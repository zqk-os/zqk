# Release Notes: ZQK Knowledge Kernel v0.3.7

**Release Version**: `v0.3.7`  
**Target Date**: November 2026  
**Commit Range**: `v0.3.6..HEAD`  

---

## Highlights & Strategic Capabilities

The `v0.3.7` release delivers the distributed community kernel capabilities across Cycles 141–169, introducing Byzantine fault tolerant consensus, cryptographic attestation and zero-knowledge proofs, planetary Merkle DAG synchronization, CRDT state convergence, peer verification mesh gating, autonomous swarm scheduling, scheduler daemon hygiene, concurrency/durable-write fixes, and repository-wide DRY and blank-check refactoring:

### 1. BFT Consensus, Quorum Slicing & Partition Recovery (`pkg/community/bft_consensus.go`, `pkg/community/byzantine_leader_election.go`, `pkg/community/bft_relay.go`, `pkg/community/partition_reconciler.go`)
- **Planetary Swarm BFT Consensus & Quorum Slicing**: Added quorum-sliced Byzantine fault tolerant consensus (`bft_consensus.go`) and adversarial Byzantine leader election with partition recovery (`byzantine_leader_election.go`).
- **Byzantine Fault Tolerant Relay & Actor Quarantining**: Implemented deduplicated peer broadcast relay (`bft_relay.go`) paired with a swarm Byzantine fault detector and malicious actor quarantining (`byzantine_detector.go`).
- **Split-Brain Detection & Reconciliation**: Added Raft-lite consensus heartbeats and split-brain lease fencing (`raft_leader.go`), swarm partition detection (`partition_detector.go`), and deterministic split-brain reconciliation (`partition_reconciler.go`).

### 2. Cryptographic Attestation, Zero-Knowledge Proofs & Audit Ledger (`pkg/community/zk_attestation.go`, `pkg/community/zk_proof_exchange.go`, `pkg/community/workload_attestation.go`, `pkg/community/audit_ledger.go`)
- **Zero-Knowledge State Attestation & Proof Exchange**: Added zero-knowledge state attestation and membership proofs (`zk_attestation.go`) along with cross-tenant zero-knowledge proof exchange (`zk_proof_exchange.go`).
- **Workload Integrity & Merkle Evidence**: Implemented cryptographic workload integrity proofs (`workload_attestation.go`) and a cryptographic ledger audit trail with Merkle tree evidence verification (`audit_ledger.go`).

### 3. Planetary Merkle DAG Sync, CRDT Convergence & State Replication (`pkg/community/merkle_dag_sync.go`, `pkg/community/crdt_convergence.go`, `pkg/community/state_replication.go`, `pkg/community/snapshot_sync.go`, `pkg/community/vector_clock.go`)
- **Merkle DAG Synchronization & Differential Range Proofs**: Added planetary Merkle DAG state synchronization with differential range proofs (`merkle_dag_sync.go`) and asynchronous state machine replication with Merkle log compaction (`state_replication.go`).
- **CRDT Convergence & Snapshot Sync**: Implemented adaptive conflict resolution with deterministic CRDT state convergence (`crdt_convergence.go`), cross-region distributed snapshot synchronization (`snapshot_sync.go`), and a distributed causal vector clock and epistemic shockwave settlement engine (`vector_clock.go`).

### 4. Peer Verification Mesh, Privacy-Preserving Gossip & Federated Exchange (`pkg/community/verification_mesh.go`, `pkg/community/differential_privacy_gossip.go`, `pkg/community/dynamic_mesh.go`, `pkg/community/federated_exchange.go`, `pkg/community/tenant_namespace.go`)
- **Peer Verification Mesh & Release Notes Elaboration Gate**: Introduced the peer verification mesh (`verification_mesh.go`) and the automated release notes elaboration gate (`pkg/releasegate/release_notes_check.go`) enforcing section completeness, minimum elaboration length, and zero internal kernel ID leaks.
- **Privacy-Preserving Gossip & Dynamic Mesh Topologies**: Added differential state gossip (`differential_privacy_gossip.go`), multi-cluster peer gossip sync (`peer_gossip.go`), autonomous swarm dynamic mesh topologies with epistemic P2P routing (`dynamic_mesh.go`), and a cross-cluster epistemic state bridge (`epistemic_bridge.go`).
- **Federated Exchange & Tenant Virtualization**: Added federated knowledge exchange dialect and ontological mapping (`federated_exchange.go`) and multi-tenant namespace virtualization with boundary enforcement (`tenant_namespace.go`).

### 5. Elastic Swarm Scheduling, Work-Stealing & Autonomous Synthesis (`pkg/community/work_stealing.go`, `pkg/community/runway_governor.go`, `pkg/community/worker_supervisor.go`, `pkg/community/workflow_assembler.go`, `pkg/community/dynamic_agent_synthesizer.go`, `pkg/community/intent_ast.go`, `pkg/community/semantic_router.go`)
- **Distributed Work-Stealing & Capacity Governance**: Added distributed work-stealing and dynamic swarm load balancing (`work_stealing.go`), elastic agent scheduling with an adaptive runway capacity governor (`runway_governor.go`), and distributed ephemeral lock leasing with barrier synchronization (`lock_lease.go`).
- **Fleet Health & Graceful Drain**: Implemented the autonomous worker health supervisor and process auto-healing controller (`worker_supervisor.go`), agent node graceful drain controller (`node_drain.go`), and swarm fleet heartbeat aggregator (`fleet_heartbeat.go`).
- **Declarative Pipeline Assembly & Semantic Routing**: Added declarative workflow pipeline self-assembly (`workflow_assembler.go`), abstract intent tree compilation (`intent_ast.go`), autonomous dynamic agent synthesis (`dynamic_agent_synthesizer.go`), and hyper-dimensional semantic routing with topology-aware context multiplexing (`semantic_router.go`).

### 6. CAS Generational Compaction, Knowledge Pruning & Semantic Deduplication (`pkg/community/cas_compactor.go`, `pkg/community/knowledge_pruner.go`, `pkg/community/semantic_dedup.go`)
- **Storage Reclamation & Graph Compaction**: Added the CAS generational compaction and storage reclamation engine (`cas_compactor.go`), autonomous knowledge pruning and obsolete graph compaction (`knowledge_pruner.go`), and semantic knowledge deduplication (`semantic_dedup.go`).

### 7. Scheduler Hygiene, Concurrency & Durable-Write Hardening
- **Scheduler Daemon Stability**: Eliminated scheduler daemon scan churn, reaped stale `SCH-AUTOFIX` jobs, scheduled `resource-hygiene`, and drained `INV` started-without-complete jobs.
- **Concurrency & Atomic Storage Fixes**: Eliminated a TOCTOU race in `filecas` `Update` by reading hashes under `WithSweepLock`, switched `WriteSecureJSONIndent` to `WriteDurableSecureFile` to prevent torn concurrent reads, resolved data races in `SupervisorAdapter` lifecycle and `RunAtLoad`, and cached fallback `spec_index.json` loads via `stampmemo`.

## Upgrade Guide

- **Backwards Compatibility**: Fully backwards compatible with existing `.zqk/process` repositories and schemas.
- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -fsSL https://zqk.dev/install.sh | bash
  ```
- **Fallback GitHub Raw Mirror**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **Post-Upgrade Verification**:
  ```bash
  zqk system check --refresh-cache
  zqk workflow whats-next
  ```
