# Release Notes: ZQK Knowledge Kernel v0.5.0 — Progressive Disclosure & Pilot ROI Suite (`zqk init --lite --with-mcp`, Executive Markdown Scorecards & CI Compliance Gates)

**Release Version**: `v0.5.0`  
**Target Date**: November 2026  
**Commit Range**: `v0.4.0..HEAD`  

---

## Highlights & Strategic Capabilities

Building directly on the `v0.4.0` Polyglot `zgrep` AST and zero-bloat onboarding foundation, `v0.5.0` delivers the complete **Progressive Disclosure & Pilot ROI Suite** so engineering teams and design partners can onboard multi-host IDEs in a single command, export Day-0 vs. Day-25 token-savings scorecards for executive reviews, and enforce `zgrep` agent compliance directly inside CI/PR pipelines:

### 1. One-Command Multi-Host MCP Wiring (`zqk init --lite --with-mcp`) (`cmd/zqk/system/init.go`, `cmd/zqk/system/init_lite.go`)
- **Zero-Manual-Config IDE Activation**: Extended `zqk init --lite` with `--with-mcp`, automatically invoking `mcp.AutoInstall` with local-binary isolation across detected Cursor, Claude Code, Windsurf, and Cline configurations—while preserving the zero-bloat `.zqk/{cache,logs,state}` footprint (no `.zqk/process` CAS objects seeded until the team opts in via `zqk init --merge`).
- **Verified Help Parity & Isolation**: Added `TestInitLite_WithMCPFlag` and updated the `zqk system init` help golden baseline so all CLI help checks pass deterministically.

### 2. Day-25 Executive Markdown ROI Scorecard (`zqk grep --roi -f markdown`) (`cmd/zqk/grep/grep.go`, `cmd/zqk/grep/grep_roi_test.go`)
- **Drop-In Slack, Notion & Renewal Review Tables**: Added `-f markdown` (and `-f md` alias) output to `zqk grep --roi`, rendering a clean GitHub-Flavored Markdown table with repository path, telemetry log source, total search invocations, compliant `zgrep` invocations, raw shell search interceptions, compliance ratio percentage, and estimated context tokens saved.

### 3. Fail-Closed CI Compliance Threshold Gate (`zqk grep --roi --min-compliance`) (`cmd/zqk/grep/grep.go`, `cmd/zqk/grep/grep_roi_test.go`)
- **Automated PR & CI Enforcement**: Added `--min-compliance <0..100>` to `zqk grep --roi` so teams can enforce a minimum `zgrep` compliance percentage in CI workflows (e.g., `zqk grep --roi --min-compliance 80`).
- **Strict Boundary Validation**: Rejects invalid threshold ranges (`< 0` or `> 100`) with a clear diagnostic error and fails closed with a non-zero exit code whenever recorded compliance falls below the configured threshold.

### 4. Polyglot AST Engine Hygiene (`pkg/search/ast_polyglot.go`)
- **Canonical Kind Alias Table**: Refactored `matchASTKind` from a multi-branch `switch` into a canonical `astKindAliases` lookup table, eliminating DRY duplication warnings in `zqk-vet` while preserving cross-language `--kind` normalization across TypeScript/JS, Python, Rust, and Go.

## Upgrade Guide

- **Backwards Compatibility**: Fully backwards compatible with existing `.zqk/process` repositories, schemas, and `v0.4.0` workspaces.
- **Upgrade Command (Homebrew)**:
  ```bash
  brew upgrade zqk-os/tap/zqk
  ```
- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -fsSL https://zqk.dev/install.sh | bash
  ```
- **Fallback GitHub Raw Mirror**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **New `v0.5.0` Commands to Try**:
  ```bash
  # Zero-bloat zgrep-first setup + automatic multi-host MCP wiring:
  zqk init --lite --with-mcp

  # Export a Markdown Day-25 ROI scorecard for Slack / Notion / exec review:
  zqk grep --roi -f markdown

  # Enforce >= 80% agent zgrep compliance in CI:
  zqk grep --roi --min-compliance 80
  ```
