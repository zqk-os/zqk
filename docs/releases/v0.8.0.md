## Highlights & Strategic Capabilities

`v0.8.0` advances ZQK's **Deterministic Evaluation & Benchmark Telemetry** and **Storage Runtime Resilience**, delivering native Markdown scorecards for CI job summaries, the Study 3 compaction-drift evaluation engine, and a fail-safe `HashRegistry` fix for cancelled async request contexts:

### 1. Deterministic Markdown Eval Scorecards (`pkg/eval/markdown_report.go`, `cmd/zqk/eval/eval.go`)
- **CI & PR-Ready Markdown Output (`zqk eval run -f markdown`)**: Added `eval.FormatEvalResultMarkdown(*eval.EvalResult)` and wired global `-f markdown` / `-f md` and `-f json` output formats into `zqk eval run` (consistent with `zqk eval llm-scrutiny`), enabling one-line piping to `$GITHUB_STEP_SUMMARY` or PR comments.
- **Deterministic Plain-Text Ordering**: Quality dimension scores in `zqk eval run` plain-text output are now sorted alphabetically for deterministic logs and diff comparison.

### 2. Study 3 Compaction Drift & Fail-Closed Done-Gate Benchmark Engine (`pkg/eval/drift_benchmark.go`)
- **Quantify Advisory Prose Decay vs. Fail-Closed Gates**: Added `eval.SummarizeDriftBenchmark` to compute deterministic cross-arm turn-bucket violation curves (`1-10`, `11-20`, `21-30`, `31-40`), `SilentFalseDoneRatePc`, `PrePRCatchRatePc`, `AvgRecoveryRetries`, and `AvgGateOverheadTokens`.
- **Reproducible Publication Artifacts**: Added `eval.FormatDriftCurveCSV` (`results/drift_by_turn.csv` schema) and `eval.FormatDriftReportMarkdown` for benchmark reporting.

### 3. Storage Resilience — Cancelled-Context `HashRegistry` Panic Elimination (`pkg/storage/object_storage_file_hash_registry_impl.go`, `pkg/storage/object_storage_file_create_helpers_impl.go`)
- **Zero Nil-Pointer Panics in Async Audit Persistence**: `(*FileObjectStorage).newHashRegistry` now detaches request cancellation via `context.WithoutCancel(ctx)` before calling `f.hashRegistryCache.GetOrCreate`, preventing cancelled request contexts from returning a `nil` `*HashRegistry` and panicking `coordinator_audit_router` goroutines during CAS writes.
- **Defense-in-Depth Nil Guard & Regression Coverage**: Guarded `hashRegistry` in `writeObjectToCAS` and added `TestFileObjectStorage_NewHashRegistry_CancelledContextReturnsNonNil`.
