## Highlights & Strategic Capabilities

`v0.8.0` advances ZQK's **CI-Native Markdown Telemetry**, **Open-Weight & Local-First IDE Ecosystem Parity**, **Study 2/3 Reproducible Benchmark Engines**, and **Storage & Audit Runtime Resilience**:

### 1. Unified CI & PR GitHub-Flavored Markdown Scorecards (`-f markdown|md`)
Pipe deterministic GFM scorecards directly into `$GITHUB_STEP_SUMMARY` or PR comments across 6 core CLI surfaces:
- **`zqk grep --bench -f markdown|md`** (`pkg/search/bench.go`, `cmd/zqk/grep/grep.go`): Self-benchmark token reduction and latency tables.
- **`zqk eval run -f markdown|md|json`** (`pkg/eval/markdown_report.go`, `cmd/zqk/eval/eval.go`): Scenario evaluation scorecards with deterministic alphabetically sorted dimension scores.
- **`zqk eval matrix -f markdown|md|json`** (`pkg/eval/markdown_report.go`, `cmd/zqk/eval/eval.go`): Multi-model convergence matrix reports.
- **`zqk workflow vds evaluate -f markdown|md`** (`pkg/vds/markdown_report.go`, `cmd/zqk/workflow/vds.go`): VDS release/launch done-gate scorecards.
- **`zqk gate list -f markdown|md`** (`pkg/gate/markdown.go`, `cmd/zqk/gate/list.go`): Gate approval queue reports.
- **`zqk test discover -f markdown|md`** (`cmd/zqk/test/discover.go`): Discovered test suite inventory with deterministic language sorting.

### 2. Open-Weight Inference & Local-First IDE Ecosystem Parity
- **Expanded Open-Weight Presets (`pkg/llm/openweight_presets.go`)**: Added `openrouter` (`OPENROUTER_API_KEY`) and `deepseek` (`DEEPSEEK_API_KEY`) alongside `ollama`, `together`, `fireworks`, `baseten`, and `groq`.
- **Multi-Host IDE & CLI Harness Adapters (`pkg/adapters/ide/`, `pkg/agentonboard/`)**: Added workspace & global config adapters for **Zed** (`.zed/settings.json`), **Continue.dev** (`.continue/config.yaml`), and **Aider** (`.aider.conf.yml`), paired with `pkg/agentonboard` host detection and boot packs.
- **Updated Ecosystem Guide (`docs/guides/OPEN_WEIGHT_AND_IDE_ECOSYSTEM_GUIDE.md`)**: Documented all 7 open-weight inference presets, 11 coding harnesses, and CI Markdown scorecard commands.

### 3. Study 2 Portable Handoff Codec & Study 3 Compaction Drift Engine
- **Fail-Closed `HandoffPacket` Codec (`pkg/sessionpaging/handoff.go`)**: Added `ParseHandoffPacketJSON` and `ValidateHandoffPacket` for strict cross-agent handoff verification.
- **Study 3 Compaction Drift Engine (`pkg/eval/drift_benchmark.go`)**: Added `SummarizeDriftBenchmark`, `FormatDriftCurveCSV`, `FormatDriftReportMarkdown`, and streaming JSONL codec (`WriteDriftObservationJSONL`, `LoadDriftObservationsJSONL`).

### 4. Storage, Audit & Release-Gate Resilience
- **Eliminated `HashRegistry` Cancelled-Context Panic (`pkg/storage/`)**: Detached request cancellation via `context.WithoutCancel(ctx)` in `(*FileObjectStorage).newHashRegistry` with nil-guard defense in `writeObjectToCAS` (`TDE-1795581372405537000-4af96eb2`).
- **Guarded `StorageAuditRouter.Emit` Against Audit-on-Audit Recursion (`pkg/coordination/routers.go`)**: Skips recursive audit emission when `targetKind == objects.KindAuditEvent`.
- **Homebrew Formula Automation Gate (`pkg/releasegate/homebrew_formula_script_test.go`)**: Added fail-closed & dry-run regression tests for `scripts/open-core/update-homebrew-formula.sh`.

## Upgrade Guide

- **Backwards Compatibility**: Fully backwards compatible with `v0.7.0` `.zqk/process` workspaces and CLI scripts.
- **Upgrade Command (Homebrew)**:
  ```bash
  brew upgrade zqk-os/tap/zqk
  ```
- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -sSL https://zqk.dev/install.sh | sh
  ```
- **Try Markdown Scorecards in CI**:
  ```bash
  zqk grep --bench "func " -f markdown >> "$GITHUB_STEP_SUMMARY"
  zqk eval run --template .zqk/eval/templates/go-ast-hygiene.yaml --target pkg/eval --auto-mint=false -f markdown >> "$GITHUB_STEP_SUMMARY"
  zqk workflow vds evaluate -f markdown >> "$GITHUB_STEP_SUMMARY"
  ```
