## Highlights & Strategic Capabilities

`v0.7.0` delivers the **60-Second Product-Led Growth (PLG) & Reproducible Benchmarking Suite**, **Native-First Agent UX**, and **Draft-Plane Gate Discoverability** (resolving community issues `#1237`, `#1249`, and `#1250` and bringing open issues on `zqk-os/zqk` to zero):

### 1. Zero-Pollution Standalone `zgrep` Mode (`pkg/search/cache_path.go`, `pkg/search/engine.go`)
- **Clean Git Working Tree Out of the Box**: Running `zgrep <query>` or `zqk grep <query>` inside any uninitialized Git repository now stores persistent trigram caches outside the working tree under `$XDG_CACHE_HOME/zqk/<repo-hash>/trigram.idx` (falling back to `os.UserCacheDir()`), leaving `git status --porcelain` 100% clean.
- **Seamless Upgrade Path**: Initialized workspaces (containing `.zqk/` from `zqk init` or `zqk init --lite`) continue storing caches at `<repo>/.zqk/cache/trigram.idx` with full backwards compatibility.

### 2. Instant Self-Benchmark (`zqk grep --bench <query>`) (`pkg/search/bench.go`, `cmd/zqk/grep/grep.go`)
- **Prove Token Savings on Your Own Repo in 2 Seconds**: Added `--bench` to `zqk grep` / `zgrep`, running an in-process side-by-side comparison of unbudgeted raw search vs. token-budgeted indexed `zgrep` JSON output on the user's own repository with zero external binary dependencies.
- **Deterministic Human & Machine Output**: Reports wall-clock latency (ms), matches returned, payload bytes, estimated BPE tokens, token reduction percentage, and estimated cost saved per 100 agent turns in table (`default`), `-f json`, or `-f yaml` formats.

### 3. Study 1 Cold-Index Honest Cost Accounting (`pkg/search/engine.go`, `pkg/search/types.go`, `cmd/zqk/grep/grep.go`)
- **Reproducible Benchmark Telemetry**: Added `search.IndexBuildStats` (`indexed_files`, `build_duration_ms`, `index_bytes`, `cache_path`) and `Engine.BuildTrigramIndexStats(opts)`.
- **JSON Reindex Output**: Running `zqk grep --reindex -f json` emits structured cold-index build timing and disk footprint telemetry directly for empirical benchmark harnesses.

### 4. Native-First Agent UX & Deterministic `zqk test bind --auto` (`cmd/zqk/test/bind.go`, `cmd/zqk/system/zqk_expert_skill_template.go`, `scripts/default_personas/`, `scripts/default_agent_skills/`)
- **Deterministic `TST → CRIT → REQ` Graph Traversal**: `zqk test bind --auto` now deterministically traverses `TST.criteria_refs → CRIT.requirement_refs` before falling back to lexical title similarity, preventing false fuzzy matches against starter requirements (`REQ-STARTER-COMMUNITY-001`).
- **Native-First Anti-Reinvention Primitive Map**: Updated `zqk-expert/SKILL.md`, seeded personas (`PER-COMMUNITY-TPM`, `PER-COMMUNITY-SOFTWARE-ENGINEER`, `PER-COMMUNITY-QA-AUDITOR`), default agent skills, and the embedded bootstrap archive (`SEED IMPERMEABILITY: PASS`) to explicitly surface `zqk eval validate|run|matrix`, `zqk gate stage|review|approve|reject`, `zqk test discover|bind|run|dashboard`, `zqk new object-spec`, and `zqk pack`.

### 5. Draft-Plane `zqk gate list` Discoverability (`pkg/gate/gate.go`, `cmd/zqk/gate/gate_test.go`)
- **Immediate Staged Gate Visibility**: `zqk gate list` (and `--status staged`) now merges Draft Plane `approval_request` objects (`.zqk/object_drafts/approval_request/`) with materialized CAS records, deduplicating by ID and sorting deterministically by `created_at` descending—so newly staged `APR-*` requests are immediately discoverable right after `zqk gate stage`.

### 6. CI Velocity & Documentation Portal Discoverability (`.github/workflows/ci.yml`, `docs/INDEX.md`)
- **Automatic Superseded Run Cancellation**: Added `concurrency: group: ci-${{ github.workflow }}-${{ github.ref }}` with `cancel-in-progress: true` to `.github/workflows/ci.yml` so rapid merges and force-pushes never starve release workflows.
- **Docs Portal Indexing**: Linked `docs/guides/ZGREP_POLYGLOT_AND_PILOT_ROI_GUIDE.md` in `docs/INDEX.md` and updated the guide with standalone XDG `zgrep` and `--bench` workflows.


