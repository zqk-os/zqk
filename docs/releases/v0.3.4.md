# Release Notes: ZQK Knowledge Kernel v0.3.4

**Release Version**: `v0.3.4` (Release Candidate `v0.3.4-rc1`)  
**Target Date**: November 2026  
**Commit Range**: `v0.3.3..HEAD`  

---

## Highlights & Strategic Capabilities

The `v0.3.4` release of ZQK delivers critical operational hardening, architectural decoupling, and developer ergonomics improvements across the Knowledge Kernel:

### 1. Zero-Vendor Hardcoding & Pluggable IDE Host Adapters
- **Decoupled Architecture**: Decoupled all host assistant and IDE specific logic into dedicated adapter packages (`pkg/adapters/ide/`).
- **Core Purity**: Zero vendor-specific hacks, string literals, or hardcoded paths exist within core kernel packages.
- **Pluggable Integration**: Seamless support for diverse coding assistants and editor hosts via standard interface contracts.

### 2. Zero-Duplication Matrix Coverage Consolidation (`pkg/coverage`)
- **Single-Pass Testing**: Eliminated redundant monolithic test runs in CI; statement coverage profiles are captured during primary partitioned execution.
- **Deterministic Aggregation**: Downstream Go merger (`pkg/coverage/merger.go`) normalizes and merges statement execution counts across matrix shards in sub-second time.
- **Negative Boundary Invariants**: Fail-closed verification prevents profile corruption, mismatched execution modes, or path traversals.

### 3. Dynamic Kernel Object Resolution in Automation Scripts
- **Resilient Tooling**: Eliminated hardcoded kernel object IDs across shell scripts and release hooks.
- **CLI Query Integration**: Scripts dynamically resolve stage, criteria, and object status via `zqk object get <id> --format json`.

### 4. High-Performance Object Graph Validation (`cmd/zqk/system`)
- **Streaming Validation Pipeline**: Resolved spurious pre-commit timeouts on large object graphs (>3,000 objects).
- **Sub-3s Latency**: Parallel batch loaders and streaming CAS indexes validate complete graphs in under 3.0 seconds.

### 5. Multi-Daemon Process I/O & File Descriptor Hygiene
- **Strict Leak Detection**: Codified and verified `<100` open file descriptor ceiling across all long-running daemons.
- **Live Daemon Health**: Verified scheduler, steward, ambient, privileged-writer, and IDE adapters operate with minimal descriptor footprint (13–43 open FDs).

## Upgrade Guide

- **Zero Breaking Changes**: Fully backwards compatible with existing `.zqk/process` repositories and schemas.
- **Upgrade Command**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **Post-Upgrade Verification**:
  ```bash
  zqk system check --refresh-cache
  zqk workflow whats-next
  ```
