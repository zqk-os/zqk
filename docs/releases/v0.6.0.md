## Highlights & Strategic Capabilities

Building directly on the `v0.5.0` Progressive Disclosure & Pilot ROI Suite, `v0.6.0` delivers **Enterprise Multi-Repo Pilot ROI Rollups, Rolling Time-Window Compliance Gates, Day-1 PreToolUse Hook Onboarding, and Zero-Drift CI Verification**:

### 1. Multi-Repo Pilot ROI Rollup (`zqk grep --roi --repos <dir1,dir2>`) (`pkg/search/interceptor/compliance_telemetry.go`, `cmd/zqk/grep/grep.go`)
- **Organization-Wide Executive Scorecards**: Added `--repos <dir1,dir2,...>` to `zqk grep --roi` backed by `interceptor.SummarizeComplianceMulti`, aggregating `zgrep` compliance ratios, raw shell search interceptions, and estimated context tokens saved across multiple microservice repositories in a single scorecard (`table`, `json`, `yaml`, or `markdown`).
- **Clean Telemetry Attribution**: Multi-repo scorecards clearly label the aggregated repository set and `multi-repo rollup (N repositories)` telemetry source.

### 2. Rolling Time-Window Filtering (`zqk grep --roi --since 7d|24h|RFC3339`) (`pkg/search/interceptor/compliance_telemetry.go`, `cmd/zqk/grep/grep.go`)
- **Week-1 vs. Week-4 Adoption Velocity**: Added `--since <duration|RFC3339>` (supporting day shorthands like `7d` and `30d`, Go durations like `24h`, and RFC3339 UTC timestamps) via `interceptor.ParseSinceWindow`, `SummarizeComplianceSince`, and `SummarizeComplianceMultiSince`.
- **Fair Rolling CI Threshold Gates**: Composes seamlessly with `--repos` and `--min-compliance` (e.g., `zqk grep --roi --repos ./svc-a,./svc-b --since 7d --min-compliance 80 -f markdown`) so rolling 7-day compliance gates measure current team behavior without being penalized by Week-1 onboarding dips.

### 3. Day-1 Compliance Hook Installer (`zqk init --lite --with-hooks`) (`cmd/zqk/system/init.go`, `cmd/zqk/system/init_lite.go`)
- **Zero-Bloat Automatic Telemetry**: Added `--with-hooks` to `zqk init --lite`, installing a non-destructive `.agents/hooks.json` (and `.agent/hooks.json` when `.agent/` exists) `PreToolUse` hook for `run_command` that invokes `zqk agent hook pre-command`.
- **Full Day-1 Activation in One Command**: Teams can now run `zqk init --lite --with-mcp --with-hooks` to warm the trigram index, generate multi-host IDE rules, wire MCP, and activate `zgrep` compliance telemetry in `.zqk/logs/zgrep_compliance.jsonl` without seeding `.zqk/process` CAS objects. Existing hook files are preserved unless `--force` is passed.

### 4. Drop-In GitHub Actions Compliance Gate Template (`docs/guides/examples/zgrep-compliance-gate.yml`)
- **Copy-Pasteable PR Enforcement**: Added a production-ready GitHub Actions workflow template that posts `zqk grep --roi -f markdown` directly into `GITHUB_STEP_SUMMARY` and enforces `--min-compliance 80` on pull requests.

### 5. Verification Engine (`zqk-vet`) DRY Hygiene Burndown
- **Cleaner Static Analysis Baseline**: Eliminated 5 `zqk-vet` DRY duplication warnings across `cmd/zqk/agent/hook_pre_command.go`, `pkg/search/interceptor/compliance_telemetry.go`, `pkg/eval/regression_gate.go`, `pkg/ambient/tool_sensor.go`, and `pkg/validation/instance_validator.go`.

## Upgrade Guide

- **Backwards Compatibility**: Fully backwards compatible with existing `.zqk/process` repositories, schemas, and `v0.5.0` workspaces.
- **Upgrade Command (Homebrew)**:
  ```bash
  brew upgrade zqk-os/tap/zqk
  ```
- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -sSL https://zqk.dev/install.sh | sh
  ```
- **Quickstart (Day-1 Zero-Bloat Pilot Setup)**:
  ```bash
  zqk init --lite --with-mcp --with-hooks
  zqk grep --roi --since 7d -f markdown --min-compliance 80
  ```
