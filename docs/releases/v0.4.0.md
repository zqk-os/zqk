# Release Notes: ZQK Knowledge Kernel v0.4.0 — Polyglot `zgrep` AST (TS/JS, Python, Rust & Go), Default Agent Compliance & Pilot ROI Scorecard, Zero-Bloat `zqk init --lite`, and Cold Episodic Paging

**Release Version**: `v0.4.0`  
**Target Date**: November 2026  
**Commit Range**: `v0.3.8..HEAD`  

---

## Highlights & Strategic Capabilities

The `v0.4.0` release marks a major milestone for AI-heavy software engineering teams running Cursor, Claude Code, Windsurf, Cline, or Antigravity across modern polyglot repositories. Rather than requiring Go-only repositories or heavy upfront ceremony, `v0.4.0` delivers **sub-15ms zero-dependency polyglot AST search**, **default-on agent `zgrep` compliance steering and ROI scorecards**, **60-second zero-bloat onboarding (`zqk init --lite`)**, **cold episodic context paging**, and **automated human-readable GitHub Release notes**:

### 1. Zero-Dependency Polyglot `zgrep` AST Engine — TypeScript/JS, Python, Rust & Go (`pkg/search/ast_polyglot.go`, `pkg/search/ast.go`, `pkg/search/engine.go`)
- **Multi-Language Structural Queries Without CGo or Tree-Sitter**: Extended `zqk grep --ast` beyond Go (`go/parser`) to natively parse **TypeScript/JavaScript** (`.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`), **Python** (`.py`, `.pyi`), and **Rust** (`.rs`) in pure Go with zero external binary dependencies.
- **Cross-Language Kind & Receiver Normalization**: Supports `--kind` (`func`, `method`, `struct`, `class`, `interface`, `trait`, `enum`, `type`) and `--recv` (Go receivers, TypeScript/Python class methods, Rust `impl` blocks) with strict `--max-tokens` JSON budgeting so agents never blow context windows on multi-language monorepos.

### 2. Default-On `zgrep` Decision Rubric, Non-Compliance Steering & Durable Telemetry (`pkg/agentonboard/payload.go`, `pkg/search/interceptor/compliance_telemetry.go`, `cmd/zqk/agent/hook_pre_command.go`)
- **Actionable When / When-Not Rubric**: Embedded a crisp `zgrep` decision rubric directly into `zqk system agent-onboard` directives so AI coding agents know immediately when to use `zgrep` (codebase discovery, symbol lookup, token-budgeted JSON) versus standard file reads (known single-file path inspection).
- **Non-Compliance Steering & Telemetry**: Every intercepted `grep`/`rg`/`git grep` command and repo-wide `find` passthrough now emits actionable steering feedback and appends structured compliance observations to `.zqk/logs/zgrep_compliance.jsonl` with concurrent write safety.

### 3. Pilot ROI Compliance Scorecard (`cmd/zqk/grep/grep.go`, `cmd/zqk/grep/grep_roi_test.go`)
- **Quantifiable Day-0 vs. Day-25 Token Savings (`zqk grep --roi`)**: Added `--roi` (supporting human-readable scorecard, `-f json`, and `-f yaml` outputs) backed by `.zqk/logs/zgrep_compliance.jsonl`, reporting total search invocations, compliant `zgrep` calls, intercepted raw shell searches, compliance percentage, and estimated context tokens saved.
- **Updated Polyglot CLI Help Surface**: Refreshed `zqk grep --help` examples and descriptions to highlight polyglot AST queries and `--roi` scorecards.

### 4. Zero-Bloat Progressive Disclosure Onboarding (`cmd/zqk/system/init.go`, `cmd/zqk/system/init_lite.go`)
- **Land with `zgrep`, Expand to Kernel (`zqk init --lite`)**: Added a zero-bloat initialization mode that creates minimal `.zqk/{cache,logs,state}` directories, generates multi-host IDE rules, and warms the persistent trigram search index in seconds—without seeding the full `.zqk/process` CAS ontology.
- **Seamless Upgrade Bridge**: Teams can evaluate sub-15ms polyglot `zgrep` and ROI telemetry immediately, then opt into full Knowledge Kernel governance at any time via `zqk init --merge`.

### 5. Cold Episodic Context Paging & Token Budget Enforcement (`cmd/zqk/context/`, `pkg/context/`)
- **Bounded Agent Context Recall**: Introduced cold episodic storage, snapshot/recall commands (`zqk context snapshot`, `zqk context recall`), and deterministic token-budget enforcement so long-running multi-agent sessions preserve institutional memory without exhausting LLM context limits.

### 6. Automated Human-Readable GitHub Release Notes Enforcement (`.github/workflows/release.yml`)
- **Fail-Closed Release Pipeline**: Updated the release workflow to verify `docs/releases/<tag>.md` exists before publishing, pass it directly to GoReleaser (`--release-notes`), and synchronize the published GitHub Release body so every public release ships with complete human-readable documentation.

## Upgrade Guide

- **Backwards Compatibility**: Fully backwards compatible with existing `.zqk/process` repositories, schemas, and `v0.3.x` workspaces.
- **Upgrade Command (Homebrew)**:
  ```bash
  brew upgrade zqk-os/tap/zqk
  ```
- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -fsSL https://zqk.dev/install.sh | bash
  ```
- **Fallback GitHub Raw Mirror**:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **Quickstart & Post-Upgrade Verification**:
  ```bash
  # New polyglot repo (zero-bloat 60-second setup):
  zqk init --lite

  # Structural polyglot AST search across TS/JS, Python, Rust & Go:
  zqk grep --ast --kind struct

  # Inspect zgrep compliance ratio & estimated tokens saved:
  zqk grep --roi

  # Existing Knowledge Kernel workspace check:
  zqk system check --refresh-cache
  zqk workflow whats-next
  ```
