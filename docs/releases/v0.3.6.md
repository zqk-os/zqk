# Release Notes: ZQK Knowledge Kernel v0.3.6

**Release Version**: `v0.3.6`  
**Target Date**: November 2026  
**Commit Range**: `v0.3.5..HEAD`  

---

## Highlights & Strategic Capabilities

The `v0.3.6` release completes the Autonomous Provider Infrastructure and Ecosystem Extensibility framework, introducing decentralized provider federation, dynamic sharding, capability matching, OpenTelemetry distributed tracing, autoscaling, and declarative code hygiene invariants:

### 1. Ecosystem Provider Consistent Sharding & Partition Balancing (`pkg/community/consistent_hash.go`)
- **Deterministic Virtual-Node Sharding**: 150 virtual nodes per replica distributing load evenly across heterogeneous provider instances.
- **Dynamic Topology Rebalancing**: Real-time addition and removal of provider nodes with minimal key migration.
- **Failover Redundancy**: Multi-replica fallback dispatch ensuring zero message drop during provider churn.

### 2. Semantic Capability Vector Indexing & Provider Matching (`pkg/community/semantic_matcher.go`)
- **Cosine Similarity Matching**: High-dimensional vector space indexing for matching unstructured intent briefs with provider capabilities.
- **Threshold Gating**: Strict confidence watermarks rejecting low-scoring or unverified providers.
- **Adversarial Input Validation**: Hardened validation protecting matching routines against degenerate or malformed feature vectors.

### 3. Declarative Blank Check Primitives & AST Anti-Pattern Invariant (`pkg/stringutil/`, `pkg/vet/`)
- **Functional Validation Primitives**: Added `stringutil.ErrorOnBlank`, `strutil.ErrorOnBlank`, and `strutil.RequireNonBlank` to eliminate boilerplate imperative validation.
- **Static Analysis Invariant (`zqk-vet`)**: Codified `hygiene/anti_pattern_blank_check` AST rule flagging procedural `if strings.TrimSpace(...) == "" { return fmt.Errorf(...) }` across all packages.
- **Architectural Policy Codification**: Registered ADR and persistent policy enforcing declarative, functional validation throughout the kernel.

### 4. Autonomous Provider Cost Accounting & Budget Governor (`pkg/community/cost_accounting.go`)
- **Micro-Cent Granularity**: Real-time token, execution time, and storage cost tracking per provider call.
- **Hard Budget Enforcement**: Proactive pre-flight budget checks halting execution before exceeding caller-configured ceilings.
- **Audit Traceability**: Immutable accounting records linked to tenant namespaces and priority plans.

### 5. Cryptographic Attestation & Audit Notary (`pkg/community/attestation.go`)
- **SHA-256 Receipt Verification**: Cryptographically signed execution receipts proving provider output provenance.
- **Tamper-Evident State Hashes**: Merkle-backed validation of state transitions and deliverable artifacts.
- **CAS Integration**: Verification tokens persisted directly into Knowledge Kernel content-addressable storage.

### 6. Fault Injection & Chaos Resilience Harness (`pkg/community/fault_injection.go`)
- **Probabilistic Chaos Engine**: Controlled latency injection, error simulation, and packet dropping for provider fault-tolerance testing.
- **Blast-Radius Containment**: Strict tenant and test-harness isolation preventing leak into production workloads.
- **Self-Healing Verification**: Automated verification of circuit breakers and exponential backoff retry mechanisms under sustained chaos.

### 7. Capability Negotiation & Protocol Handshake (`pkg/community/capability_negotiation.go`)
- **Bidirectional Handshake**: Dynamic feature negotiation between core swarms and external provider nodes.
- **Version Compatibility Matrix**: Semantic version negotiation preventing incompatible schema exchanges.
- **Secure Key Exchange**: Mutual authentication and ephemeral session token generation for peer agents.

### 8. Distributed Tracing & OpenTelemetry Bridge (`pkg/community/distributed_tracing.go`)
- **W3C TraceContext Invariant**: High-entropy 16-byte `trace_id` and 8-byte `span_id` propagation conforming to OpenTelemetry specifications.
- **Cross-Process Propagation**: Distributed context headers serializable across CLI commands, HTTP webhooks, and MCP mesh invocations.
- **Trace Sampling & Exporter**: Structured telemetry export for Jaeger, Prometheus, and external observability platforms.

### 9. Dynamic Resource Autoscaling & Capacity Governor (`pkg/community/resource_autoscaler.go`)
- **Dynamic Fleet Sizing**: Autonomous concurrency scaling responding to queue pressure, task complexity, and latency trends.
- **Watermark Thresholds**: Configurable scale-up (80%) and scale-down (30%) watermarks preventing flapping and resource starvation.
- **Adversarial Safety Bounds**: Strict bounds checks refusing non-positive concurrency limits or infinite worker allocations.

### 10. Documentation Portal Scrutinizer & Zero-Leak Quality Gate (`scripts/open-core/docs-portal/`)
- **Per-Topic Character Limits**: Enforced maximum character length per topic to prevent documentation bloat and maintain scannability.
- **Canonical Terminology Registry**: Deduplicated acronyms and standardized definitions across the public portal.
- **Internal Cycle Narrative Purging**: Filtered internal development retrospectives and cycle logs from public-facing articles.
- **Zero Kernel ID Leaks**: `zqk-vet -suite docs` quality gate blocking publication of project-specific internal IDs (`REQ-*`, `CRIT-*`, `BLI-*`) in public guides.

## Upgrade Guide

- **Upgrade Command (Direct Domain)**:
  ```bash
  curl -fsSL https://zqk.dev/install.sh | bash
  ```

  ```bash
  curl -fsSL https://raw.githubusercontent.com/zqk-os/zqk/main/scripts/install.sh | bash
  ```
- **Post-Upgrade Verification**:
  ```bash
  zqk system check --refresh-cache
  zqk workflow whats-next
  ```
