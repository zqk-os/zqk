# Archived agent onboarding summaries

Dated **`AGENT_ONBOARDING_SUMMARY_YYYY-MM-DD.md`** files live here. They captured **session snapshots** (live `priority_plan`, `convergence_session`, backlog pointers, and “what to run next”) and are kept for audit and narrative continuity.

**Do not start onboarding from these files.** Use:

1. **[../AI_AGENT_ONBOARDING.md](../AI_AGENT_ONBOARDING.md)** — canonical guide  
2. **[../AGENT_ONBOARDING_SNAPSHOT.md](../AGENT_ONBOARDING_SNAPSHOT.md)** — current focus (refresh periodically)  
3. **[../AGENT_ONBOARDING_SUMMARIES_DIGEST.md](../AGENT_ONBOARDING_SUMMARIES_DIGEST.md)** — compressed history distilled from the archive  

Registered **`doc_entry`** objects still point at these paths (updated when files were moved).
