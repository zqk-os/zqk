# Rubric: L-DOCS-MODEL

**Lens:** `L-DOCS-MODEL` · **Density:** D-LOW (Top N) · **Axes:** RDB, OPS, CMP

## Criteria

1. Can a stranger form a correct mental model from README + architecture docs?  
2. Docs match code (CMP).  
3. Glossaries / domain language consistency.  
4. “How to change X” discoverability.  
5. Dangerous outdated docs (worse than none).
