**Last Verified:** 2026-08-31


**Status**: Active

## Architecture
The `Capability` object provides the structured linkage between abstract intentions generated by an agent's LLM (e.g., "Refactor storage layer") and concrete, permissioned policy executions. It acts as an orchestrator boundary.

### Core Concepts
- **Capability**: A defined, permissioned ability (e.g., `fs:read`, `shell:execute`, `kernel:update_schema`).
- **Intent**: The semantic goal requesting the capability.
- **Policy Binding**: The evaluation block determining if the `Capability` is authorized under the current context profile.

### Interfaces
```go
package capability

import "context"

// Policy Evaluation Context
type EvalContext struct {
	AgentID      string
	WorkspaceDir string
	RequestedScope map[string]string
}

type Capability interface {
	Name() string
	Description() string
	EvaluatePolicy(ctx context.Context, evalCtx EvalContext) (bool, error)
}

type Registry interface {
	Register(c Capability) error
	Get(name string) (Capability, error)
	List() []Capability
}
```
