# Multi-Agent Validation Pipeline

## Overview
The Multi-Agent Validation Pipeline ensures that code mutations generated by autonomous swarm workers are independently verified before merging.

## Pipeline Stages
1. **Mutation Detection (INGEST):** Listens for `proposed` changes in the integration branch.
2. **Heuristic Sandboxing (NORMALIZE):** Executes `make verify` in an isolated chroot/docker context.
3. **Peer Review (DECIDE):** Spawns an `Architectural Reviewer` persona to check AST compliance and policy adherence (e.g., `POL-CODE-007`).
4. **AutoFixer Execution (COMMIT):** If the reviewer detects regressions (e.g., undefined variables), it routes the exact diff to the `AutoFixer` agent which attempts targeted AST patching (via `multi_replace_file_content`).
