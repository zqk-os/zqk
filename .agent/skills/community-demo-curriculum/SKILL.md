# Greenfield Demo Curriculum & Public Adoption

## Objective
Provide structured methodologies for building showcase projects from scratch using the ZQK core kernel, authoring reproducible screen-recording demo scripts, and creating high-impact YouTube video walkthroughs that drive developer adoption.

## Core Protocols

### 1. Zero-to-One Greenfield Walkthrough
- Begin from an empty directory: `zqk init` -> verify configuration -> initialize mission & vision.
- Mint the 5-layer cascade interactively (`goal` -> `priority_plan` -> `requirement` -> `test_case` -> `backlog_item`).
- Demonstrate immediate AST-verified autonomous execution via `zqk do` or `zqk agent orchestrate`.

### 2. Screen-Recording Demo Script Standards
- Concise terminal pacing: commands execute cleanly with visible output and clear explanations.
- Highlight the Knowledge Kernel differentiator: explain why ZQK graph objects beat transient chat harnesses.
- Demonstrate deterministic failure recovery: show how a broken invariant or failing test triggers self-healing rather than hallucination.
